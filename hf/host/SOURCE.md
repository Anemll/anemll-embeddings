Apache-2.0 allows this redistribution. Files listed as **copied verbatim**
are byte-identical to the upstream objects. The embedding table is the
exception: it is **extracted** from `model.safetensors` tensor
`language_model.embed_tokens.weight` (BF16 `[262144, 512]`) and stored as
`embed_tokens.safetensors` with Gemma's `embed_scale = sqrt(512)` recorded
beside the raw matrix. The full 1.49 GB `model.safetensors` is **not**
mirrored.

See `LICENSE` and `NOTICE` in this folder (and at the repo root).

Run `python scripts/prepare_hf_host_folder.py` on the upload Mac to fill
this folder (payload files, `SHA256SUMS`, and the checksum table below).
